[02 // SYSTEM ARCHITECTURE & CAPABILITIES]

Engineered Like a Systems Runtime, Not a Wrapper Script

Strict unidirectional layering (features -> ui/app -> domain -> lib), deterministic command serialization, and native terminal rendering.

01 // GRAPH ENGINE domain/graph

Two-Cell Lazygit Box-Drawing Lanes

Renders complex branch topologies and octopus merges using East Asian Ambiguous 1-cell glyphs. Switch seamlessly between rounded arc corners (╭ ╮ ╰ ╯ ○ ◎) and WGL4/CP437-safe sharp corners (┌ ┐ └ ┘ +) with cursor-paginated history and instant commit search (/).

Glyphs: U+2500..U+257F Page window: 500 commits
02 // GUARDED GIT CLI domain/git + commands

Serialized Runner & Zero Shell Interpolation

Every Git subprocess spawns via argument arrays with no shell interpretation. Write operations are strictly serialized (one mutation at a time with explicit blocked reasons), credentials in URLs and stderr are automatically redacted, and branch deletion inspects unmerged commit risk before confirmation.

Spawn: argv[] only Safety: Credential Redaction
03 // DIFF & TREE-SITTER features/diff + parsers

Vendored WASM Syntax Highlighting

Working tree, staged, untracked, commit, stash, and conflict diffs render through OpenTUI's unified <diff> primitive with vendored Tree-sitter WASM grammars (TypeScript, Python, Rust, Go, Bash, JSON, YAML, HTML, CSS, Java, PHP). Unchanged context runs collapse cleanly and scroll via J/K/H/L.

View: Unified 1-Gutter Parsers: Offline WASM
04 // INPUT & FOCUS AUTHORITY app/hooks/useHotkeys

Context-Sensitive Keys + Full Mouse Support

A single global key dispatcher resolves precedence (Overlay -> Text Editor -> Native Select -> Focused Region -> Global). Every keyboard action has mouse parity: click to focus and select, double-click to trigger primary actions, click checkboxes/headers, and scroll any viewport with the wheel.

Regions: 1..9 + Tab Mouse: Click / DblClick / Wheel
05 // COMPLETE REPO SURFACES features/branches..worktrees

Branches, Remotes, Tags [LR], Stashes & Worktrees

Manage the entire Git lifecycle without leaving the viewport: checkout/create/delete branches, prune remotes, inspect tag presence via the fixed-width [LR] / [L↑] / [L?] matrix, pop/apply stashes with untracked files, and create or prune linked Git worktrees.

Tag Matrix: [L R ↑ ?] Frame-Buffer Progress Bar
06 // CATPPUCCIN & COLOR ENGINE domain/theme

Truecolor, 256-Color & Monochrome Fallback

Ships with four official Catppuccin flavors (mocha, macchiato, frappe, latte). Inspects NO_COLOR, COLORTERM, and TERM at startup to adapt automatically between 24-bit truecolor, quantized xterm-256color, and high-contrast monochrome.

Default: catppuccin-mocha Live Reload: Ctrl+P
