## Configuration

gitminal reads an optional config file from `~/.config/gitminal/config.json` (or `$GITMINAL_CONFIG` when set, and `$XDG_CONFIG_HOME/gitminal/config.json` when `XDG_CONFIG_HOME` is set). All fields are optional; anything missing keeps its default.

### Keyboard shortcuts

Every keyboard action has a name, and each name maps to one or more key specs. Overriding an action replaces its defaults.

```json
{
	"keybindings": {
		"quit": ["q", "escape"]
	}
}
```

Key specs are written as `modifier+key`, for example `ctrl+c`, `shift+tab`, `alt+left`, or just `left`, `enter`, `escape`, `tab`, `backspace`, `delete`, `pageup`, `pagedown`, `q`. Recognized modifiers are `ctrl` (alias `control`), `shift`, and `alt` (aliases `option`, `meta`).

Available actions:

- `quit` - exit gitminal (default: `q`).
- `pull` - run the default pull (default: `p`).
- `push` - run the default push (default: `shift+p`).
- `open-remote-menu` - open the remote operations menu (default: `.`).
- `move-down` - move the menu selection down (default: `down`).
- `move-up` - move the menu selection up (default: `up`).
- `activate-selection` - run the highlighted menu command (default: `enter`).
- `close-overlay` - close the menu (default: `escape`).
- `toggle-mouse` - enable or disable mouse reporting, for example to select text (default: `m`).

An invalid or malformed config file is ignored and the defaults are used; a warning is printed to stderr.
